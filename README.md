## Descripción

**Linux vs PowerShell** es una guía práctica que compara los comandos más utilizados en sistemas Linux y Windows PowerShell.

El objetivo del proyecto es facilitar la transición entre ambos sistemas operativos mostrando las equivalencias entre comandos, explicando sus diferencias y proporcionando ejemplos reales de uso.
