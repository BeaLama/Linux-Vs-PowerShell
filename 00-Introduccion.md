# Introducción

Bienvenido a **Linux vs PowerShell**.

Este repositorio nace con el objetivo de facilitar el aprendizaje y la administración de sistemas Linux y Windows mediante una comparación directa entre los comandos y herramientas más utilizados en ambos entornos.

A lo largo del proyecto encontrarás equivalencias entre comandos de Bash y PowerShell, explicaciones sobre sus diferencias, ejemplos prácticos y casos reales de administración.

No pretende ser un manual completo de Linux ni de PowerShell, sino una guía de referencia organizada por niveles de dificultad para ayudarte a comprender cómo realizar las mismas tareas en ambos sistemas.

---

# Objetivos

Los principales objetivos de este repositorio son:

- Aprender la equivalencia entre comandos Linux y PowerShell.
- Comprender las diferencias entre ambos entornos.
- Facilitar la transición entre Windows y Linux.
- Disponer de una guía de consulta rápida durante tareas de administración.
- Mostrar ejemplos prácticos aplicables en entornos reales.

---

# ¿A quién va dirigido?

Este repositorio está pensado para:

- Administradores de sistemas.
- Técnicos de soporte IT.
- Estudiantes de informática.
- Personas que estén aprendiendo Linux.
- Personas que estén aprendiendo PowerShell.
- Profesionales que trabajen en entornos híbridos Windows/Linux.

No es necesario tener conocimientos avanzados. Los contenidos están organizados de forma progresiva para que puedas avanzar desde los conceptos fundamentales hasta tareas de administración y automatización.

# Filosofía del proyecto

El objetivo no es memorizar comandos, sino comprender cómo resolver una misma tarea en dos entornos diferentes.

Siempre que sea posible, cada documento mostrará:

- El objetivo de la tarea.
- La solución en Linux.
- La solución en PowerShell.
- Las diferencias entre ambas.
- Ejemplos prácticos.
- Buenas prácticas.
- Errores habituales.

De esta forma podrás entender no solo **qué comando utilizar**, sino también **por qué funciona de manera diferente en cada sistema**.
